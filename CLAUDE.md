# SABRA! — pixel-art 2D platformer about everyday life in Israel

Vanilla JS ES modules, no build. Run: `python3 -m http.server 8080` → http://localhost:8080/
Spec: `CONTRACT.md` (binding for all modules). Smoke test in headless Chrome: `node tools/smoke.mjs [--level N]`.
Validators: `node tools/check-level.mjs src/levels/levelN.js`, `node tools/check-art.mjs src/art/X.js`.
